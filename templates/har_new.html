导入抓包

怎么抓包（Chrome / Edge）：
1. 打开目标站点并登录 → 按 F12 → 切到 Network 面板
2. 勾上 「保留日志 / Preserve log」（很重要，否则跳转后记录会清空）
3. 点一下「清空」→ 手动完成一次签到操作
4. 在网络请求列表里右键 → 「另存为带内容的 HAR」 → 保存文件
5. 回到这里上传该文件
文件只在浏览器里读成文本，之后随表单一起提交，不会上传到别处
Chrome 里：右键请求 → Copy → Copy as cURL (bash)，然后粘到这里
取消

步骤 2：确认要执行的请求

启用 方法 URL 状态
静态资源（.js/.css/图片等）已默认取消勾选。只勾选「签到真正需要的那几个请求」， 通常就是 1~3 个。
取消
