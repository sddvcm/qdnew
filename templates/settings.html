程序更新
更新源是一个 GitHub 仓库，其根目录需有 update_manifest.json 清单文件， 里面列出文件名与 SHA256。程序会比对版本号、逐个校验哈希后才写入，并自动备份旧文件。
格式：https://github.com/用户名/仓库名，非默认分支加 /tree/分支名。 只允许 github.com 域下的地址。
当服务器直连 raw.githubusercontent.com 超时（如国内网络）时使用。 填你电脑上 Clash / v2rayN 等代理的局域网地址（代理软件需开启 「允许局域网连接 / Allow LAN」），飞牛才能访问到它。留空则直连。
配置后「检查更新 / 立即更新」都会经此代理访问 GitHub。

改完代码后：填上新版本号 → 下载 update_manifest.json → 连同改动一起提交到仓库根目录。之后在任意部署点「检查更新」即可拿到新版本。

本地验证码识别
安装包默认不含本地识别所需的库（ddddocr + OpenCV + ONNX，约 400MB）， 验证码走云码。想用本地识别（免费、不联网、无额度限制）就在这里上传组件包开通， 之后可在下方切换识别方式。

任务里的「验证码识别方式」留空时用这里的设置；任务里单独选了则以任务为准。
auto 会先用本地识别（省钱），本地不可用或失败时自动改用云码。
去 www.jfbym.com 注册，用户中心复制 Token。填这里可以让所有任务共用一个 Token，不用每个任务填一遍。
默认 10110 = 通用数英（≤5 位），Discuz 登录验证码用这个即可。
选择 captcha-local-pack-*.zip 组件包（约 130MB，走内网传输即可）。 安装后自动启用，无需重启。组件包存在数据目录里，升级程序不会丢。

任务导出 / 导入
导出一个加密的配置文件（后缀 .qdpack），用于备份、 换机迁移或分享给别人。文件含账号密码，已用本程序专属密钥加密 —— 只有本程序能读取，其他程序或编辑器打不开。
导出范围

⚠️ 换到别的机器导入时，两边的应用密钥必须一致（同一 fpk 升级/重装不会变）。
